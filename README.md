# Roamly offline

Мобильное приложение для поездок компаний и гидов, которое работает без интернета.
ТЗ и макеты ведутся в Claude.

## Сборка 0.1 (Android, тестовая)

Что есть:
- светлая и тёмная тема, русский интерфейс;
- поездки: создание с типом (пешком, на машинах, яхта), участники, дети, кошельки;
- чат поездки, точка сбора;
- траты: валюта и курс, категории, деление по правилам (дети %), поровну или вручную;
- балансы кошельков, минимум переводов, отметка «Вернул»;
- план по дням;
- SOS: звонок 112 и пакет для спасателей;
- QR приглашения (пока только показ кода);
- режим трафика и «Подготовить к роумингу» (чек-лист).

Всё хранится только на телефоне (SQLite). Связь телефон-телефон, карты, фото и вход через аккаунты — следующие сборки.

## Как собирается

GitHub Actions (`.github/workflows/android.yml`) на каждый push в `main`:
генерирует Android-проект (`flutter create`), проверяет код (`flutter analyze`) и собирает
`app-release.apk`. Готовый APK — во вкладке Actions → последний запуск → Artifacts → `roamly-apk`.

Пакет приложения: `com.roamlyoffline.roamly`.
